# Bundled font sources

`JetBrainsMonoNerdFontMono-{Regular,Bold,Italic}.ttf` are unmodified files from
[Nerd Fonts v3.4.0](https://github.com/ryanoasis/nerd-fonts/tree/v3.4.0/patched-fonts/JetBrainsMono/Ligatures),
based on **JetBrains Mono 2.304**, with Nerd Fonts' additional icon glyphs.
